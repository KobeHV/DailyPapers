# Polya's Problem-Solving Framework

## 定义
数学家 George Polya 提出的经典数学解题方法论，包含四个步骤：理解问题（Understand）、制定计划（Plan）、执行计划（Execute）、回顾反思（Look Back）。

## 核心要点
1. 1945 年提出，至今仍是数学教育领域的基石框架
2. 在 AI 辅导中被用作结构化的思维引导 prompt
3. 实验证明基于 Polya 框架的提示优于通用提示，尤其在结合 Thinking Reward 时

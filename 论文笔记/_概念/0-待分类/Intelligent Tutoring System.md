# Intelligent Tutoring System

## 定义
利用人工智能技术模拟人类教师的一对一辅导过程，为学生提供个性化学习指导、即时反馈和适应性教学的计算机系统。

## 核心要点
1. LLM 的出现使 ITS 从基于规则的系统转向自然语言交互
2. 关键挑战：避免直接泄露答案（Leak）、提供有帮助的引导（Helpfulness）、考虑学生个体差异
3. RL 训练是提升 LLM 导师教学效果的有效方法
